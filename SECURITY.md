# Security Policy — XaynxAI

XaynxAI takes the security and privacy of our users and infrastructure seriously.

## Reporting a Vulnerability

If you discover a security vulnerability in **xaynxai.com**, our APIs, or any XaynxAI service, please report it responsibly **in private** before public disclosure:

- **Email:** [contact@xaynx.com](mailto:contact@xaynx.com)
- **Subject:** `[SECURITY] Brief summary of the issue`

### What to Include
- Clear description of the vulnerability and potential impact
- Step-by-step reproduction instructions (or proof-of-concept)
- Affected URL, endpoint, or feature

### Guidelines
- Do **not** access, modify, or exfiltrate other users' data.
- Do **not** perform Denial-of-Service (DoS/DDoS) or automated destructive testing.
- Give us reasonable time to investigate and remediate before any public disclosure.

We review all valid reports promptly and appreciate responsible researchers helping keep XaynxAI safe.
